# Task 6: Host a Static Website with GitHub Pages

## Objective
Deploy a simple HTML website using GitHub Pages.

## Tools
HTML, CSS, GitHub, GitHub Pages

## Live Website
https://er-dhananjay.github.io/static-website-github-pages/

## Steps
1. Created `index.html` and `style.css`
2. Pushed the code to this GitHub repo
3. Settings > Pages > Source: Deploy from a branch > `main` / `(root)`
4. Opened the live link given by GitHub

## Files
- `index.html`: main page
- `style.css`: styling
- `screenshots/`: Pages settings and live site
